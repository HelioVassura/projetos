> Script em Python desenvolvido para auxilio na campanha de conscientização ambiental de companhias de saneamento, classificando o consumo e emitindo alertas aos moradores.

---

## 📌 Objetivo do Sistema

O objetivo deste software é analisar o perfil de consumo de água ($m^3$) de diferentes tipos de imóveis (comercial, casa ou apartamento) e emitir alertas educativos automáticos de acordo com os limites preestabelecidos.

---

## ⚙️ Regras de Negócio

- **Comercial**: Alerta para consulta do plano corporativo.
- **Apartamento (< 10 m³)**: Consumo econômico.
- **Apartamento ou Casa (até 25 m³)**: Consumo moderado dentro do padrão.
- **Outros casos**: Alerta de consumo excessivo e verificação de vazamentos.
