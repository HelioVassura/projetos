# Pesquisa de Satisfação de Atendimento - TudoWeb 📊

Projeto desenvolvido em Python para a empresa de marketing **TudoWeb**, com o objetivo de realizar uma pesquisa de opinião junto aos seus clientes e avaliar o grau de satisfação com o atendimento prestado.

O sistema realiza a coleta de informações dos entrevistados, incluindo nome, idade e opinião sobre o serviço recebido. Para garantir a confiabilidade dos dados, o programa possui validação de entradas, aceitando apenas idades numéricas e positivas, além de um menu interativo para o registo da opinião do cliente.

Também foram implementados mecanismos de tratamento de erros utilizando blocos `try/except`, evitando que a aplicação seja encerrada devido a entradas inválidas. Ao final da pesquisa, o sistema gera automaticamente um relatório com a quantidade de respostas classificadas como **EXCELENTE** e **RUIM**, permitindo uma análise rápida da satisfação dos clientes.

O projeto foi configurado inicialmente para entrevistar 10 clientes durante os testes, podendo ser facilmente ajustado para 50 entrevistados ou mais na versão final.
