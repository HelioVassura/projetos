# ⚡ Calculadora de Consumo de Energia

## 📌 Sobre o projeto

Este projeto foi desenvolvido em **Python** com o objetivo de calcular o consumo estimado de energia elétrica de um aparelho durante um mês.

Neste exemplo, o aparelho utilizado é uma **geladeira**, com potência de **250 W** e utilização média de **12 horas por dia**.

O programa realiza o cálculo automaticamente e apresenta o consumo estimado em **kWh/mês**.

## 🎯 Objetivo

O objetivo do sistema é facilitar a estimativa do consumo mensal de energia de um aparelho elétrico, utilizando sua potência e o tempo de utilização diário.

## 🐍 Linguagem utilizada

* 🐍 **Python**

## 🧮 Fórmula utilizada

O cálculo é realizado utilizando a seguinte fórmula:

**Consumo mensal = (Potência × Horas por dia × 30) ÷ 1000**

Onde:

* **Potência:** potência do aparelho em watts (W).
* **Horas por dia:** quantidade de horas que o aparelho é utilizado diariamente.
* **30:** quantidade aproximada de dias em um mês.
* **1000:** conversão de watts para quilowatts.

### 📊 Exemplo

Para uma geladeira de **250 W**, utilizada durante **12 horas por dia**:

**(250 × 12 × 30) ÷ 1000 = 90 kWh/mês**

Portanto, o consumo estimado é de **90 kWh por mês**.

## ▶️ Como executar o programa

1. Certifique-se de ter o **Python** instalado no computador.
2. Baixe ou clone este projeto.
3. Abra a pasta do projeto no **Visual Studio Code** ou outro editor.
4. Abra o arquivo `consumo_energia.py`.
5. Execute o programa pelo terminal com:

```bash
python consumo_energia.py
```

6. O resultado do consumo será apresentado no terminal.
